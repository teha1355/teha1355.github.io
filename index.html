Project 1: Telephone Number Input

Here is the link to the website. The goal was to create an infuriating way to input a phone number. The Telephone Number Input is a nightmare for anyone who struggles with memory games.

The user has to match cards in order to input a phone number. However, there are cards that aren't numbers that can mess up the input. Once a mistake has been made, the user has to restart, and the cards are shuffled.

Project 2: Pokemon Synth

A synth made in Cycling '74 Max.

The synth's theme is Pokemon. The user is able to adjust the oscillator type, the multiplier, the pulse width, the gain, the resonance, and the frequency cutoff. In addition, there are 3 song presets.

Project 3: 3D Printed Willow Tree Lamp

The goal was to 3D print a willow tree lamp but with moving chain link leaves. The following image is a first iteration, and the second iteration is currently in progress.

In this iteration, the main focus was an organic tree shape and chain leaves that could move in any direction. I wanted to avoid glueing and tried to 3D print whole pieces.

Process

The below image is the final dimensions for the leaf chain connections. After several attempts, this design allowed for movement, while keeping the leaves a leaf shape.
