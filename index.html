Project 1: Telephone Number Input

The Telephone Number Input is a nightmare for anyone who struggles with memory games.

In order to input a digit of the phone number, a pair of cards needs to be correctly matched. However, there is only one pair of cards for each number, and the rest of the cards are the letter L. If a mistake is made, for instance inputing the letter L or an incorrect number, there is no back space, and the user has to restart the process. Clicking the restart button reshuffles all of the cards.

Project 2: Pokemon Synth

A synth made in Cycling '74 Max.

The synth's theme is Pokemon. The user is able to adjust the oscillator type, the multiplier, the pulse width, the gain, the resonance, and the frequency cutoff. There are three preset songs or the user can use the keyboard to play their own notes.
